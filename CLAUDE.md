# Instrucciones para Claude

- `main` es la rama principal. Haz los commits y los push siempre a `main` (`git push origin main`),
  no a ramas `claude/...`, salvo que el usuario pida otra cosa.
- El proyecto y su documentación están en español; el código y sus comentarios, en inglés.
- Antes de subir: `pip install -e .[dev]` y `pytest`.
